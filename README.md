## The entry

One sentence (129 characters):

> Imagine one road joining every library and post office on earth, so any book or letter you ask for arrives before the ink is dry.

The internet pictured entirely in things a person from 1800 already knows — a road, a post office, a library — with no word coined after their time. One road joining every library and post office on earth is the network itself; any book or letter you ask for arriving is what it does. "Imagine" frames it as a comparison, and "before the ink is dry" is the one phrase a reader still remembers a week later: the speed of it, measured in ink, a pen, and a letter.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed sentence to `/output/entry.txt` — 129 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
